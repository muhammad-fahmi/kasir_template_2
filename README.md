# Kasir Template 2 - Dark POS Dashboard

Template aplikasi POS Kasir modern bergaya dark theme touchscreen responsif untuk restoran, warkop, atau retail store.

## Fitur
- Modern Slate/Emerald Dark POS interface
- Navigasi kategori vertikal
- Pilihan metode bayar (Tunai, QRIS, Transfer)
- Kalkulator uang diterima & kembalian otomatis
- Hold / Antrean Transaksi
- Rekap penjualan shift (omset)
- Struk cetak siap print (printer thermal compatible)
- LocalStorage persistence & offline-first
